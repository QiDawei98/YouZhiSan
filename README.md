# YouZhiSan

Software for analysing optical spectroscopy of trivalent rare earth ions using crystal field theory.

## Introduction

This program is designed to use Crystal Field Hamiltonian to reproduce experimentally observed levels of trivalent rare earth ions. We use Stevens normalisation as a perturbation on the 4f free-ion states.

A parallel multi-stage optimisation engine is implemented and benchmarked.

Includes a built-in dataset of Stevens equivalent operators for excited terms of trivalent rare-earth ions.

Robust and easy to use.

## Dependencies

Requires a decent computer with Python 3 installed. Anaconda is recommended.

This program is built upon [PyCrystalField](https://github.com/asche1/PyCrystalField). Installing it will give you everything you need.
